Лабораторная работа №1 – функции ввода/вывода, условный оператор

## Формулировка заданий

1. Напишите программу, которая вычисляет площадь треугольника по трем его сторонам (по формуле Герона) с точностью до сотых.
2. Создать программу-конвертер, которая переводит расстояние из одних единиц измерения в другие (Километры, Метры, Сантиметры, Миллиметры, Мили, Ярды).
3. Написать программу, которая определяет, является ли введённый год високосным согласно правилам григорианского календаря.

## Среда разработки

Язык программирования: Python.
Среда разработки: PyCharm / VS Code (или любой другой редактор с установленным Python).

## Инструкция по работе

**Задание 1 (Площадь треугольника):** запустите `task1.py`. По запросу программы введите три числа (стороны треугольника) — каждое в своей строке. Числа могут быть как целыми, так и дробными. Программа рассчитает площадь и выведет результат с двумя знаками после запятой.

**Задание 2 (Конвертер расстояний):** запустите `task2.py`.
1. Введите исходную единицу измерения (`км`, `м`, `см`, `мм`, `mi`, `yd`).
2. Введите целевую единицу измерения.
3. Введите значение для конвертации.
Программа выведет результат перевода.

**Задание 3 (Високосный год):** запустите `task3.py`. По запросу программы введите год (целое число). Программа проверяет его по условиям (делится на 4, но не делится на 100, либо делится на 400) и выводит сообщение о том, является ли год високосным.
